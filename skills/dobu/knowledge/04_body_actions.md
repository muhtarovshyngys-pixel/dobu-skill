# Добу — экшны тела и стиль анимации

## Стиль (как делали раньше)
- Мультяшно, не реалистично, смешные движения, но **не дёргано**. Сильные силуэты: голова огромная, поэтому позы читаются спереди. Позы в глубину кадра теряются.
- Персонажи различаются характером в теле:
  - Base — простодушный;
  - Artist — драма-квин с театральными позами (рука на лбу, голова вверх);
  - Scientist — собранный, рациональный;
  - Builder — харизматичный;
  - Farmer.
- Общие правила анимации — в навыке `character-animation-craft`:
  - ключица поднимается вместе с плечом;
  - все оси вращения работают, с отставанием по цепочке;
  - FK для рук без опоры;
  - для игровых экшнов последний кадр = первый.
- В роликах (не в игре) правило «последний кадр = первый» не обязательно: оно только для игровых лупов.

## ПЭМ (рука)
- В `Pa1m_rig_v4.blend` только служебные экшны света. Позы и экшны ПЭМ из эпизодов собраны в библиотеку поз (раздел «Библиотека поз ПЭМ» ниже).
- Для эпизодов нужна библиотека жестов ПЭМ:
  - talk short / long / question / exclamation;
  - point (указывает пальцем), stop (ладонь), grab / hold за шкирку;
  - fly-in, fly-away.
- Рука ведёт себя как персонаж:
  - кисть = «голова», пальцы = эмоции;
  - при разговоре лёгкое парение (moving hold) и акценты пальцами на ударных слогах;
  - при полёте корпус-кисть ведёт, пальцы волочатся с отставанием (overlap).

## Расстановка в layout
- Сначала позы из Asset Library (`Face_*`, позы рук `hand_*`) или экшн-позы из файлов выше, взятые кадром (append экшна, один кадр как поза).
- Болванки допустимы там, где позы ещё нет.

## Idle и Emote в игре (перенесено из face-emotion-rig, раздел 9)
- Игровые экшны делаются в **30 fps** (ролики — 24 fps).
- **Idle_X и Emote_X — разные экшны.** `D_<Персонаж>_Idle_<Эмоция>` — простой дыхательный луп: только медленное дыхание, взгляд строго вперёд, голова не поворачивается, никаких жестов. Поза = кадр 1 эмоута той же эмоции.
- Всё с жестами, поворотами головы, указанием пальцем, взмахами — `D_<Персонаж>_Emote_<Эмоция>`.
- Если в экшне `Idle_` оказался жест — переименовать его в `Emote_` (Idle → Emote, остальное имя без изменений), а `Idle_` сделать заново дыхательным (рецепт дыхания — character-animation-craft, раздел 13).
- Экшны эмоций одного персонажа могут лежать в разных .blend одной папки (например, `Dobu_Scientist_anim.blend` и `Dobu_Scientist_anim1.blend`). Если каких-то нет в открытом файле, сначала проверь соседние файлы.
- Мимика в этих экшнах — слайдер эмоций на голове (старый текстурный, CONSTANT-ключи). Без просьбы не трогать. Подозрительную интерполяцию (например, первый ключ BEZIER при остальных CONSTANT) — только сообщить.

## Библиотека поз ПЭМ (06.11.2026)
- Файл `Yandex.Disk\Dobudob\01_ASSETS\01_CHARACTERS\PA1M\01_RIG\PAM_PoseLibrary\PAM_PoseLibrary_v002.blend` (сохранён в 4.5, открывается в 5.x; риг v4 линком по относительному пути `//..\Pa1m_rig_v4.blend` + override). Папка `PAM_PoseLibrary` = корень asset library (`blender_assets.cats.txt` и контактный лист поз рядом).
- 112 ассетов-поз: каталоги `ПЭМ/<ракурс>` (Ладонь к камере, Тыльная сторона, Пальцами в камеру, Со стороны запястья, Профиль - большой палец, Профиль - мизинец) и `ПЭМ/00 Игровые (PA1M_Poses)`; превью сняты с того ракурса, как поза стояла в эпизоде. В ассетах нет c_traj/c_pos.
- Экшн `PAM_Poses_Bank` — все позы по кадру с маркерами; `PA1M_Poses`, `PA1M_Poses_12` — игровые позы пользователя из GameAssets.
